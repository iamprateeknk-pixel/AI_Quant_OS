# ADR 0173: A17 withholds evolution plans until quality gates are connected

## Decision

Register A17 0.2.0 as a PARTIAL/SHADOW paper graph mission. Bind a source-checked agent registry inventory and explicit unavailable quality, training dataset, cost, and trace observations. Return a typed WAIT_FOR_EVIDENCE report with no tournament actions, plan creation, or promotion authority.
