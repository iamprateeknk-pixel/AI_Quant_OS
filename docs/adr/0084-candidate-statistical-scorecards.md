# ADR 0084: Original-source candidate statistical scorecards

Date: 2026-10-07
Status: Accepted for local descriptive validation

## Decision

Bind one immutable typed scorecard to the original package, source-only proposed
test observation, complete holdout and complete ordered development run inventory.
Recheck native numeric execution/cost/ledger bindings before deriving screens.
Retain every required gate and its hash-bound evidence, measured failure or pending
reason. Separate immutable policy, closed-trade simulation, report composition and
operator file delivery. Reuse existing original wire models and computation methods.

Portable reports bind image/source content rather than physical archive locations;
this grants no filesystem or execution authority. Missing, duplicate, reordered,
foreign or reused worker evidence is refused. Partial final intervals remain
visible and cannot satisfy complete walk-forward/stability acceptance.

Use the exact original Monte Carlo seed/trials with completed trade cash flows.
Never invent a final liquidation or silently reduce requested trials. Unsupported
computation capacity remains pending. Independent isolation, attestation,
adversarial, reality-gap, financing, conversion, review and shadow gates remain
pending. No accepted/promotion state is defined.

## Evidence and limits

Initial tests failed on the absent producer, absent file CLI, missing retained wire
schemas, unbound gate evidence and physical-path coupling. The scripted daemon's
ownership lookup was corrected to each actual job parent, allowing independent
run roots without weakening production ownership controls.

Focused real-worker verification passed 27 checks in 122.51 seconds. The clean staged checkout passed all 27 checks in 118.01 seconds. The frozen full regression with all six local gates passed 1,956 tests, with 15 optional integrations skipped, in 1246.54 seconds. All 22 prior wire schemas match models/HEAD; 296 unchanged production/infrastructure/schema artifacts match HEAD after Git newline normalization. Lint/format (385 files), staged source/test/schema comparison and secret scan passed. See docs/evaluations/candidate-validation-0084.json. An earlier create timeout remains explicitly uncertain with its inputs/intents retained; its exact unique name inspected as absent and that job was never restarted.
The full P00–P13 goal remains incomplete. A10 mission/health integration, broader
failure archival, physical/statistical isolation, independent review, larger
computation plans and all production gates remain required.

## Review and rollback

Contracts contain policy/result invariants; simulation contains closed-ledger
resampling; composition checks original reports and derives descriptive gates;
delivery handles pinned file input/exclusive fsynced publication. The original
domain engine, worker/image/guard/policy and original wire contracts are unchanged.
Machine-readable layer rules remain undeclared; review is manual. Rollback removes
these independent producer/CLI/contracts and their artifacts. Original candidate
execution and development-window records remain compatible.

Manual five-axis review: original numeric/cost/coverage reconstruction and typed
pending gates protect correctness; focused modules keep contract, simulation,
composition and delivery responsibilities separate; no dependencies or existing
production source changed. File inputs have independent hashes, canonical parsing
and individual/aggregate bounds; publication is exclusive and fsynced. Native
sampling retains fixed capacity and performs no proposed-code or broker action.
This is a self-review, not the independent candidate acceptance review; that gate
remains pending.
