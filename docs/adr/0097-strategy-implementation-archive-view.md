# 0097: Observe saved strategy implementations without approval claims

Date: 2026-10-09

## Decision

Expose checked filesystem archive metadata through the existing protected server
session and Research route composition. Preserve the immutable implementation and
source formats, lazy dependencies, built-in construction and existing registry API.
Bound the inventory, verified bytes and response previews. Verify every manifest and
source, including off-page rows, and reject observed manifest inventory changes.
Require the ordered semantic catalog fingerprint for pagination.

## Consequences

Strategy history can be inspected without executing a saved implementation or
fabricating trading approval, performance or operating status. This read provides no
broker, capital, promotion or selection capability. Filesystem namespace trust remains
the existing host responsibility; the catalog is not a transactional audit history.
Full Strategy workflows and A12 selection still require actual eligibility evidence,
world-state/performance constraints and audited controls. Visual acceptance remains
pending after the policy-rejected local preview launch. Full-plan gates remain open.
