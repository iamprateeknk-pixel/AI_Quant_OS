# 0061: Bounded local A01 specialist supervision

Date: 2026-10-03

## Decision

Install A01 0.2.0 as a partial shadow implementation with its original fixed role
ceiling. Bind its task plan to four server-owned source records covering exact
catalog/lifecycle, effective PAPER permissions, checked world and local health
availability. Use the existing persisted GraphRuntime for every specialist.

The one orchestration tool accepts an empty payload and runtime-bound parent
context/task identity. Wake at most six supported versions sequentially, integrity
and risk evidence first, under the parent's remaining context deadline and a
five-second manifest ceiling. Compile each child with its existing source adapter
and budgets; its observation remains independently identified. Derive child IDs
from exact parent context and specialist version and reuse original receipts.
Retain uncertain calls without retry. Report typed source/permission failures and
retain graph failures without altering risk controls.

Recheck current admission before each child and current tool permission after an
awaited handler. TaskPlan source binding rejects forged selection, deferrals,
world/health/parent identity; typed call summaries enforce receipt/hash/expiry
claims. Confidence remains zero and escalation mandatory.

## Evidence and limits

Actual protected API/graph replays matched six declared development cases and
exact parent/child restart receipts. Concurrency, cancellation, revocation,
timeout/deadline, source/claim rejection and actual stale/spread order blocks
passed focused checks. Permission revocation during an awaited tool call was
reproduced before adding the post-call gate. The full regression passed with 1,285 checks and 15 skips; details are recorded in BUILD_STATUS.

Fresh-checkout verification also reproduced a Windows evaluator/recipe byte
mismatch. Canonical LF retention preserves every source/recipe line and the
regenerated six-case report matches the actual checkout hashes and current schema.

The trusted replay worker uses a bounded owned process to release cached ASGI
route closures and Windows database handles. It is not candidate isolation. Named
report pins cover three supervisor modules and evaluator, not API/runtime/registry
composition or all transitive sources. Local CSV fixtures do not replace retained
actual HTTPS provenance. Adaptive scheduling, cost/resource budgets, reputation,
calibration, distributed supervision, remaining missions, repair/evolution,
production deployment and all live/promotion gates remain open.

## Rollback

Stop the owned app and preserve all state and retained source/evaluation bytes
before reverting. No shared schema migration occurs. Older readers may not serve
A01 0.2.0 receipts; the original planned version cannot execute them.
