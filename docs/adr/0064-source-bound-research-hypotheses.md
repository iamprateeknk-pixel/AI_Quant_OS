# 0064: Source-bound prospective research hypotheses

Date: 2026-10-04

## Decision

Connect A08 0.2.0 as a partial shadow mission with SANDBOX capability scope.
Use checked training receipts and direction counts, validated completed A08
outputs, and checked archival paper-world costs. Separate its pure direction
policy, typed contracts, source publisher, graph implementation, HTTP boundary
and declared evaluator. Extract the unchanged research receipt contract from
its database implementation to keep contracts independent of storage.

Bound complete collection reads and refuse overflow rather than silently hiding
members. Validate every graph member and journal identity in one SQLite read
transaction. World reads preserve original snapshots and reject changed bytes.
Context capture checks each store separately and declares that consistency limit.
Do not run a proposed strategy, model or candidate program.

The direction screen drafts at most four prospective experiments, reports
deferred counts and suppresses signatures found in prior completed graph outputs.
Missing costs remain unavailable. Output confidence is zero, escalation required
and execution/promotion/isolation flags false. Paper resume must reject a sandbox
graph. Enabled monitoring observes the receipt before responding.

## Verification

Tests first reproduced absent mission routes, absent archive collection readers,
missing direction policy and missing evaluator. The paper resume route initially
accepted the sandbox graph; a regression reproduced the issue before the scope
gate was added. An invalid mission result initially stayed SHADOW when periodic
polling was stopped; immediate receipt observation now quarantines that version.
Five declared actual API replays verify exact restart, unchanged controls,
training-only output and prior draft suppression. Source/evaluator/fixture pins
and output schema are retained. Full regression results are in BUILD_STATUS.

## Limits and rollback

The 75%/25% screen has no significance or independent alpha acceptance. Costs
are archived paper spreads only. Per-store capture is not a cross-store atomic
observation, and concurrent contexts have no global novelty reservation.
Shared training/holdout storage has no physical or statistical isolation.
SANDBOX scope is not kernel confinement. Broader scheduling, authentic data,
calibration, strategy construction, isolated validation and promotion remain open.

Preserve all classified sources, context/graph journals, world snapshots and
quarantine state when reverting. Do not downgrade saved evidence or clear
quarantine. See RESEARCH_HYPOTHESIS_HANDOFF.md.
