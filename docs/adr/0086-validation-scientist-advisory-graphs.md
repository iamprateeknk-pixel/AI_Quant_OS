# 0086: Bind A10 advisory graphs to checked original validation archives

Date: 2026-10-08

## Decision

Register A10 0.2.0 as PARTIAL/SHADOW with the unchanged original role ceiling. Expose
only compact original-source archive summaries through three HOLDOUT-classified
inputs. Preserve dataset lineage without exposing source or dataset payloads.
Require current task/checkpoint/role admission at the retrieval tool, check the
archive against the context, and bind the output to the exact retrieval receipt.
Keep numeric evaluation and proposed-source execution outside the short graph call.
Load the optional native engine only for numeric publication; archival readers and
the base application must remain available when that dependency is absent.

Retain all fifteen gates and checked numeric metrics where they exist. Failed
prerequisites cannot contain trading statistics. Outcome and reasons must match
gate states. No accepted outcome, promotion or independent-isolation claim exists.

Connect graph receipts to the existing health observer. Candidate rejection is a
completed advisory task. Invalid metadata, agent exceptions and deadlines withhold
output and preserve the existing health/safety failure taxonomy. Quarantine applies
to the exact manifest/version; no new agent control or capital capability is added.

## Scope

This is checked archival advisory integration. Full original-source validation
orchestration, independent/adversarial/champion acceptance, physical/statistical
isolation and every production release gate remain open. See
`VALIDATION_SCIENTIST_HANDOFF.md` for routes and limits.
