# Decisions

- 2026-10-07: Bind original candidate test, holdout and complete ordered development observations to immutable descriptive statistical scorecards. Retain every required gate, exact declared Monte Carlo seed/trials and missing-evidence reasons; do not infer independence, source attestation or promotion. Portable evidence binds immutable image content rather than original archive locations. See ADR 0084.

- 2026-10-07: Keep original-source training folds in explicit retrospective dataset views with selection overlap and no independence claim. Bind each run to its exact window and passed source-only test observation; retain partial final intervals, reuse guarded custody and native BASE/stress replay, and preserve original holdout wire models. See ADR 0083.

- 2026-10-05: Exercise actual fixed Linux enforcement with trusted metadata-selected privilege/noexec, memory, CPU, process, file-size and descriptor probes. Keep production worker/guard/controller/image/contract bytes unchanged, retain owned exact terminal/removal evidence, and preserve all false authority claims. See ADR 0082.

- 2026-10-05: Compile/test original candidate and SDK bytes only in a separate source-only Linux job. Exclude dataset payloads, bind an independently retained manifest to native identities, persist intents before single create/start, require owned acknowledged removal, and retrieve retained results without execution. Preserve original package statuses and all false authority fields. See ADR 0081.

- 2026-10-05: Verify the original Linux dependency image through a metadata-only trusted probe before proposed compilation/tests. Guard the runtime before imports, compare all 51 versions, run only fixed trusted tests, retain owned intents/observations/removal, and keep certification/promotion authority false. The production candidate test executor remains a separate requirement. See ADR 0080.

- 2026-10-05: Admit actual Docker output-capture booleans without admitting interactive input; accept only empty cgroup selection and the exact protected kernel-path inventories independent of ordering. Preserve the original worker/image/recipe/custody pins. Retain observed synthetic real-engine execution as development evidence with all authority flags false. See ADR 0079.

- 2026-10-05: Run original candidate prefixes only in increasing index order under an independently pinned run manifest and append-only audit. Persist unique names before staging, stop on unknown outcomes, commit each completed receipt/archive before release, and replay the complete identical tape at BASE and declared-stress costs. Keep all execution/promotion claims false and require independent recovery pins. See ADR 0078.

- 2026-10-05: Publish an exact independently pinned recovery archive before explicitly releasing a successfully completed and audited removed prefix's known inputs. Retain archive/attempt/final observation and journal; recover partial deletion under original package/root/file bindings without recursive cleanup, daemon calls or execution authority. See ADR 0077.

- 2026-10-05: Bind complete operator-pinned successful/removed prefix receipt inventories to original invocation/source/SDK/history identities, canonical numeric tapes and independently checked native replay. Portable metadata grants no local filesystem or execution authority. Keep daemon/source attestation and all promotion gates open. See ADR 0076.

- 2026-10-05: Reserve one fixed attached strategy start before its RPC, bound output and independently check successful owned exit. Attempt exact owned kill/removal on every start path; publish only after acknowledged removal and original-input recheck. Completion remains unattested and inputs retained; offline restoration requires independent hashes. See ADR 0075.

- 2026-10-05: Bind the complete strategy create recipe to the original job/image/source and independent hashes; publish an exclusive durable attempt marker before one create RPC. Admit only exact owned created metadata and remove only by independently inspected immutable ID with audited acknowledgements. Unknown outcomes retain all custody; no worker start or automatic input release. See ADR 0074.

- 2026-10-05: Publish exact prefix-job ownership before a durable audited create intent; bind every subsequent acknowledgement to one owner/job/image/source and immutable container ID. Record history grants no runtime authority, performs no Docker action and never releases inputs automatically. Future callers must hold the public admitted-job context and independently observe actual actions. See ADR 0073.

- 2026-10-05: Stage only the exact original package's prefix JSON in a new owned directory, with metadata outside the worker mount. Require the initial independent stage hash for restoration, reject changed filesystem identities, and discard only known unstarted files without recursion or pending ownership sidecars. Host namespace trust and actual container lifecycle remain separate requirements. See ADR 0072.

- 2026-10-05: Verify one immutable strategy archive snapshot before fixed-engine handoff. Separate read-only presence inspection from a single load request; uncertain mutations retain inputs without retry or shared-image cleanup. Inspect platform/descriptor/layers/runtime config and keep execution/promotion authority false. See ADR 0071.

- 2026-10-05: Assemble the strategy worker OCI archive from independently pinned opaque worker/base bytes. Read-only hash inspection confers no execution or promotion authority. Preserve the older repair path and strategy closures; require external engine/container admission before candidate execution. See ADR 0070.

- 2026-10-07: Retain original-source compilation/proposed-test failures in a separate immutable contract without fabricated downstream metrics. - 2026-10-08: Register A10 0.2.0 as a PARTIAL/SHADOW advisory reader of checked original validation archives. - 2026-10-08: Retain original-source validation stage reservations and acknowledgements under one pinned job and audited root. - 2026-10-08: Export original validation interruption observations as exclusive independently pinned metadata files. Bind each declared stage boundary to its historical audited checkpoint; verify after pinned recovery without changing current state or asserting physical worker failure, cleanup, trading metrics or acceptance. Preserve original wire models and A10 archival capabilities. See ADR 0088.
- 2026-10-08: Observe the original source-test worker's retained custody checkpoints under its existing lease. Bind immutable canonical reports to original manifest/source/owner and exact metadata hashes; verify historical subsets after further valid records. Export outside protected custody and retain all false authority fields. No worker, retry, cleanup or wire-model change. See ADR 0089.
- 2026-10-09: Use backend-owned expiring operator grants, checked nonce-hash journals and credential rotation binding. Preserve direct authenticated emergency paper controls if the session journal is unavailable. Bind session controls to complete command identities, transactional expected-state checks and audited accepted receipts. Use an exact-origin server boundary and HttpOnly cookie in Mission Control; retain paper-only and all full-plan release gates. See ADR 0090.
